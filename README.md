# plejer.dk

Hjemmeside og webapp for Plejer: NFC-mærker på ting i hjemmet, der minder hele husstanden om det, der skal gøres igen og igen.

- `/` forsiden
- `/app/` webappen (kører i demotilstand, indtil `app/firebase-config.js` er udfyldt)
- `/privatliv.html` privatlivspolitik

Hostes på GitHub Pages med domænet plejer.dk (DNS hos Simply).
